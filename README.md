# ゆうめい専用ブラウザ（仮）

5ch 専用ブラウザ（**読み取り専用**）。広告なし、謎の通信なし。
自分のPCの中だけで動きます。

## 通信先について（大事なところ）

このアプリが通信するのは、以下の2種類だけです。

1. **あなたのPCの中**（ブラウザ ⇄ このアプリ、127.0.0.1）
2. **5ch系サーバー**（`*.5ch.net` / `*.5ch.io` / `*.bbspink.com`）と **エッヂ**（`bbs.eddibb.cc`）…板一覧・スレ一覧・DAT・過去ログの取得のみ

広告ネットワーク、アクセス解析、マイニング、その他外部サービスへの通信は一切ありません。
ソースコードは全部このフォルダにあるので、いつでも確認できます。

## 使い方

### 準備（初回だけ）

Node.js が必要です。未インストールなら https://nodejs.org/ の LTS 版を入れてください。

### 起動

`起動.bat` をダブルクリック → ブラウザが開きます。
黒いウィンドウはアプリ本体なので、使い終わるまで閉じないでください（閉じると終了します）。

### 操作

- 左：板一覧（検索つき）→ 板を選ぶ
- 中：スレ一覧（検索つき）。開いたスレはグレー表示になります
- 右：レス表示。`>>番号` をクリックでジャンプ、その人の `ID:` をクリックで同じ人のレスを全部ハイライト
- スレが終わっている（落ちている）場合は、自動で **過去ログ** を探して「過去ログ」バッジ付きで表示します
- 上の入力欄に read.cgi のスレURLを貼って「開く」でも直接開けます
- 書き込み機能はありません（読み取り専用）

## ファイル構成

- `server.js` … 本体（Node.js 標準機能のみ、依存ライブラリなし）
- `public/index.html` … 画面
- `起動.bat` … Windows用ランチャー
