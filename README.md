# ゆうめい専用ブラウザ（仮）

5ch 専用ブラウザ（**読み取り専用**）。広告なし、謎の通信なし。
自分のPCの中だけで動きます。

## 通信先について（大事なところ）

このアプリが通信するのは、以下の2種類だけです。

1. **あなたのPCの中**（ブラウザ ⇄ このアプリ、127.0.0.1）
2. **5ch系サーバー**（`*.5ch.net` / `*.5ch.io` / `*.bbspink.com`）と **エッヂ**（`bbs.eddibb.cc`）…板一覧・スレ一覧・DAT・過去ログの取得のみ

広告ネットワーク、アクセス解析、マイニング、その他外部サービスへの通信は一切ありません。
ソースコードは全部このフォルダにあるので、いつでも確認できます。

例外（画面上のスイッチでON/OFFできます）:

- **🖼 サムネ（初期ON）**：レス内の画像URLをサムネイル表示します。画像の取得は DuckDuckGo の画像プロキシ（external-content.duckduckgo.com）経由で、あなたのIPを画像サイトに直接見せないための仕組みです。OFFにすると画像は表示されません

なお、外部リンクは直接開きます（参照元URL＝リファラは送らない設定）。「リンクも DuckDuckGo 経由で開く」方式は、DDG 側のリダイレクト仕様が変わって現在は使えないため採用していません。

## 使い方

### 準備（初回だけ）

Node.js が必要です。未インストールなら https://nodejs.org/ の LTS 版を入れてください。

### 起動

`起動.bat` をダブルクリック → ブラウザが開きます。
黒いウィンドウはアプリ本体なので、使い終わるまで閉じないでください（閉じると終了します）。

### タスクバーにピン留めする（アヒルアイコン付き）

.bat は直接ピン留めできないので、ショートカット経由にします。同梱の `icon.ico`（アヒルアイコン）が使えます。

1. フォルダ内の `起動.bat` を **Shift＋右クリック →「パスのコピー」**
2. 何もない場所を右クリック →「新規作成 → ショートカット」
3. 項目の場所に `C:\Windows\System32\cmd.exe /c "ここにコピーしたパスを貼る"` と入力して作成
4. ショートカットを右クリック →「プロパティ」→「アイコンの変更」→ 同梱の `icon.ico` を選ぶ
5. 名前を「専ブラ」等に変えて、右クリック →「タスクバーにピン留めする」

これでタスクバーのアヒルを押すだけでサーバー起動＋ブラウザ表示まで一発になります。

DuckDuckGo ブラウザで開きたい場合:

- **確実な方法**：DuckDuckGo を「既定のブラウザ」に設定しておけば、`起動.bat` のままで DDG で開きます
- **専用バッチ（実験的）**：`起動-DDG.bat` を使うと、DDG を探して URL 付きで起動を試みます。DDG アプリ側の仕様で URL が渡らない環境では、DDG が素の状態で開くだけになることがあります。その場合は上の「既定のブラウザ」方式が確実です

### 操作

- 左：板一覧（検索つき）→ 板を選ぶ
- 中：スレ一覧（検索つき）。開いたスレはグレー表示になります
- 右：レス表示。`>>番号` をクリックでジャンプ、その人の `ID:` をクリックで同じ人のレスを全部ハイライト
- スレが終わっている（落ちている）場合は、自動で **過去ログ** を探して「過去ログ」バッジ付きで表示します
- 上の入力欄に read.cgi のスレURLを貼って「開く」でも直接開けます
- 書き込み機能はありません（読み取り専用）

## ファイル構成

- `server.js` … 本体（Node.js 標準機能のみ、依存ライブラリなし）
- `public/index.html` … 画面
- `起動.bat` … Windows用ランチャー
